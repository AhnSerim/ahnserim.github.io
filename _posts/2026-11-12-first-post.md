## serim.space는 어떤 곳인가

일한 내용을 토대로 공부하며 배운 것들과 읽은 책에 대한 생각을 남기는 개인 기록장이다.
잘 정리된 강의 노트라기보다는, 공부하다 막혔던 부분과 그걸 풀어낸 과정을 나중의 내가 다시 꺼내 볼 수 있도록 적어 두는 곳에 가깝다.

## 두 개의 구역

- **[Study](/study/)** — 무언갈 공부하며 정리한 노트. 개념 정리, 직접 짜 본 코드, 헷갈렸던 부분을 기록한다.
- **[Reading](/reading/)** — 읽은 책의 기록과 짧은 리뷰. 책 정보와 별점, 기억에 남은 문장을 함께 적는다.

## 우주를 떠다니는 8비트 화면

이번 리팩토링의 컨셉은 **"우주를 떠다니는 8비트 게임 화면 속의 기록장"**이다.
배경에는 픽셀 별과 행성, 작은 우주선이 떠 있고, 버튼은 오락실 키캡, 글 목록은 RPG 대화창 모양으로 만들었다.

대신 긴 글을 편하게 읽을 수 있도록 제목과 버튼에만 픽셀 폰트를 쓰고, 본문은 읽기 편한 서체로 썼다.
코드도 이렇게 보기 좋게 담을 수 있다.

```c
#include <stdio.h>

int main(void) {
    puts("Hello, serim.space!");
    return 0;
}
```
